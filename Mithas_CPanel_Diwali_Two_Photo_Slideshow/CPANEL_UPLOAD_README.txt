MITHAS - CPANEL UPDATE: OWNER'S TWO DIWALI SLIDES

This package updates the existing website's hero slideshow to use the two images provided by the owner:
- assets/diwali-slide-1.jpg
- assets/diwali-slide-2.jpg

The images alternate automatically every 5 seconds with a fade transition.
The hero text and other website sections remain in place. No Ganpati slideshow images are used in the hero.

UPLOAD:
1. cPanel -> File Manager -> public_html (or your domain document root).
2. Back up the current website files first.
3. Upload this ZIP and extract it.
4. Ensure index.html and the assets/ folder are directly inside the document root, not a nested folder.
5. Overwrite the old files when prompted.
6. Open the domain and hard-refresh with Ctrl+F5.
